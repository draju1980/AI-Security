# AI Security Fundamentals Course

A comprehensive course on securing Generative AI and Large Language Model (LLM) applications.

## Course Overview

This 9-module course covers the complete spectrum of AI security:

- **Module 0:** [Introduction to AI Security](module-0/) - AI fundamentals and threat landscape
- **Module 1:** [RAG Security Fundamentals](module-1/) - Securing retrieval-augmented generation systems
- **Module 2:** [Data Poisoning in RAG Systems](module-2/) - Defending against data poisoning attacks
- **Module 3:** [Sensitive Information Disclosure](module-3/) - Access control and privacy protection
- **Module 4:** [UnIndexed - Data Governance Failures](module-4/) - Data discovery and classification
- **Module 5:** [Lockdown - Comprehensive Security Assessment](module-5/) - Threat modeling and vulnerability assessment
- **Module 6:** [AI Security Monitoring and Defense](module-6/) - Logging, detection, and incident response
- **Module 7:** [OWASP Top 10 for LLM Applications](module-7/) - Industry security framework
- **Module 8:** [Capstone Project - Secure Enterprise AI Assistant](module-8/) - Hands-on security assessment

## Learning Outcomes

Upon completion, students will be able to:

- Understand AI/LLM fundamentals and security implications
- Identify and mitigate prompt injection attacks
- Secure RAG systems and vector databases
- Detect and prevent data poisoning
- Implement proper access controls and data classification
- Perform comprehensive AI security assessments
- Design monitoring and incident response for AI systems
- Apply OWASP Top 10 for LLM Applications framework
- Conduct threat modeling for AI systems
- Develop practical remediation plans

## Recommended Timeline

- **Instructor-led:** 3-4 weeks, 2-3 hours per week
- **Self-paced:** 4-6 weeks at own pace
- **Bootcamp format:** 2 weeks intensive

## Prerequisites

- Basic understanding of software architecture
- Familiarity with databases or APIs
- No LLM experience required

## Platform Support

Exercises use:
- ChatGPT, Claude, or Gemini
- OpenWebUI, AnythingLLM, or Ollama (optional)
- LlamaIndex or LangChain (for RAG labs)
- Standard Python/JavaScript

## Getting Started

1. Start with [Module 0: Introduction](module-0/README.md)
2. Read the README.md in each module for theory and examples
3. Follow INSTRUCTIONS.md for hands-on labs
4. Progress sequentially through modules
5. Complete capstone project in Module 8
